# Outreach Rulebook

<!--

- [R-001] Volume first: apply to every senior full-stack opening found, the same day.
- [R-002] Send to whatever address the company website lists (careers@, hr@, info@, contact@ are all fine).
- [R-003] If no address is listed, guess the hiring manager's email as first@ or first.last@ and send there.
- [R-004] Attach the general resume and personalise only the first line of the email.
- [R-005] If there is no reply after ~10 days, send the same email again to the same address.
